# آرتمیس — سیستم مدیریت فروشگاه و صندوق فروش (POS)

🌐 **[🇮🇷 فارسی](README.md) | [🇬🇧 English](README.en.md) | [🇩🇪 Deutsch](README.de.md) | [🇸🇦 العربية](README.ar.md)**

**آرتمیس** یه سیستم کامل و خوداتکای مدیریت فروشگاه و صندوق فروشه که طی دو سال، با استفاده‌ی واقعی و روزانه توی یه مغازه‌ی واقعی، تیکه‌تیکه ساخته و تکمیل شده. این پروژه از یه نیاز ساده شروع شد: فرار از هزینه‌ی نرم‌افزارهای صندوق فروشِ گرون‌قیمتِ بازار و دردسر نصب‌شون — و کم‌کم، ویژگی به ویژگی، تبدیل شد به یه پلتفرم کامل مدیریت کسب‌وکار: فروش، موجودی، مشتریان، کارمندان، حسابداری، و چاپ، همه توی یه جا.

هم به‌صورت یه اپ وب (از هر مرورگری، روی هر دستگاهی) و هم به‌صورت اپ اندروید بومی کار می‌کنه، و هر دو با پروژه‌ی [Supabase](https://supabase.com) خودت حرف می‌زنن — یعنی **کامل مالک اطلاعات خودتی**. نه هزینه‌ی ماهانه‌ای در کاره، نه وابستگی به سرورهای ما برای کارکردنش.

**ریپوزیتوری:** https://github.com/medad21/ArtemisPOS

## 🧩 برای شخصی‌سازی ساخته شده

آرتمیس محدود به یه نوع خاص از مغازه نیست. مغازه‌ای که این برنامه براش ساخته شده، کنارش کار چاپ و کپی هم انجام می‌ده، برای همین یه بخش «خدمات» بهش اضافه شد: به‌جای یه فروش ساده‌ی کالا، هر خدمت (چاپ رنگی، صحافی، کپی و…) می‌تونه به چند تا جزء هزینه‌ای تفکیک بشه (کاغذ، جوهر/تونر، دستمزد و…)، تا سود واقعی هر کار جدا از فروش خرده‌فروشی معمولی محاسبه بشه — با گزارش مخصوص خودش، تفکیک‌شده بر اساس نوع خدمت و روز. این دقیقاً همون ایده‌ی کلی پشت کل پروژه‌ست: هر بخش دقیقاً به این خاطر اضافه شده که یه نیاز واقعی و مشخص پیش اومده، و کدش هم به‌قدر کافی ساده‌ست (HTML/JS خام، بدون مرحله‌ی build) که هرکسی بتونه بازش کنه و یه بخشی رو مطابق کسب‌وکار خودش تغییر بده.

## ✨ امکانات

**فروش و صندوق**
- ثبت سریع فروش با اسکن بارکد (از طریق دوربین، بدون نیاز به سخت‌افزار اضافه)
- تخفیف، چند روش پرداخت (نقدی، کارت، کارت‌به‌کارت، نسیه/امانی)
- فروش همکاری/عمده برای معاملات بین کسب‌وکارها
- یه بخش جدای «خدمات» برای کارهای پروژه‌ای (چاپ، تعمیر، سفارش سفارشی و…) با تفکیک هزینه به اجزا و گزارش سود مخصوص خودش

**موجودی**
- ردیابی کامل موجودی با هشدار کمبود کالا
- دسته‌بندی کالا، کاردکس (تاریخچه‌ی ورود/خروج) هر کالا
- ساخت و چاپ برچسب بارکد قابل‌اسکن برای کالاهایی که بارکد ندارن

**مرجوعی و تعویض**
- مرجوعی کامل یا جزئی با اصلاح خودکار موجودی و سود
- تعویض کالا (مشتری با کالای دیگه‌ای عوضش می‌کنه)، با تسویه‌ی فقط مابه‌التفاوت — کاملاً ردیابی‌شده، نه یه راه‌حل دستی

**مشتریان**
- پروفایل مشتری، تاریخچه‌ی خرید، ردیابی بدهی
- باشگاه وفاداری/امتیازی با سطح‌های ویژه و مشتری فعال
- پیامک گروهی به بدهکاران، همه‌ی مشتریان، یا هر شماره‌ی دلخواه — چندسرویس‌دهنده (کاوه‌نگار، ملی‌پیامک، اس‌ام‌اس.آی‌آر، یا هر API سفارشی دیگه‌ای از طریق Webhook)

**مولتی‌یوزر**
- نقش مدیر و کارمند با ورود جداگانه
- ردیابی عملیات هر کارمند برای پاسخ‌گویی

**حسابداری**
- ترازنامه، چند حساب نقدی/بانکی
- ردیابی هزینه‌ها، سند افتتاحیه، پشتیبان‌گیری خودکار

**چاپ**
- پرینترهای معمولی (A4/A5/A6) و پرینترهای حرارتی فیش‌زن (۵۸/۸۰ میلی‌متر)
- چاپ مستقیم بلوتوث از اپ اندروید (بدون نیاز به درایور چاپگر سیستم)
- محتوای فاکتور کاملاً قابل‌تنظیم (چه چیزی روی فاکتور نشون داده بشه) و مبلغ به حروف

**بقیه‌ی امکانات**
- ۴ زبان: فارسی، انگلیسی، آلمانی، عربی (با پشتیبانی کامل راست‌به‌چپ)
- چند واحد پول
- حالت تاریک/روشن
- یادآوری خرید و یادآوری پرداخت چک

## 🚀 شروع کار

آرتمیس برای ذخیره‌ی اطلاعاتت به یه پروژه‌ی [Supabase](https://supabase.com) نیاز داره (نسخه‌ی رایگانش برای شروع کافیه).

۱. یه پروژه‌ی رایگان Supabase بساز.
۲. فایل برنامه (`index.html`) رو توی مرورگر باز کن — صفحه‌ی راه‌اندازی اولیه رو می‌بینی.
۳. توی SQL Editor پروژه‌ی Supabase‌ت، اسکریپت ساخت جدول‌ها رو اجرا کن (برنامه بعد از اتصال خودش می‌تونه این اسکریپت رو برات بسازه — از مسیر «تنظیمات → دانلود اسکریپت SQL»، یا از نسخه‌ی موجود توی همین ریپو استفاده کن).
۴. آدرس پروژه و کلید anon/public پروژه‌ی Supabase‌ت رو توی صفحه‌ی راه‌اندازی وارد کن.

همین — اطلاعاتت کاملاً توی پروژه‌ی Supabase خودته.

## 📱 اپ اندروید

آرتمیس با [Capacitor](https://capacitorjs.com) به‌صورت یه اپ بومی اندروید هم بسته‌بندی شده، با امکانات بومی مثل اسکن بارکد از طریق دوربین، ورود با اثر انگشت، و اعلان‌های محلی. پوشه‌ی `android/` و workflow گیت‌هاب اکشنز توی `.github/workflows/` رو برای فرایند build ببین.
